# Контракт HTTP API просмотрщика

Внутренний API для встроенного UI; не часть публичного контракта gateway. Формальное описание — [openapi.yaml](openapi.yaml). Доступен только на `127.0.0.1`. Все методы — `GET` (FR-009); любой другой метод → `405`.

| Путь | Назначение |
|------|-----------|
| `GET /api/databases[?refresh=1]` | базы, доступность, размеры, список таблиц с размерами и столбцами (FR-001, FR-002, FR-008); `refresh=1` сбрасывает кэш схемы (размеры и число строк всегда читаются заново) |
| `GET /api/databases/{db}/tables/{table}/rows` | страница строк: `q`, `filter`, `sort`, `dir`, `page`, `pageSize` (FR-003…FR-007, FR-015) |
| `GET /healthz` | живость процесса |

## Параметры `rows`
- `q` — строка поиска, до 200 символов; `ILIKE '%…%'`, спецсимволы `%`, `_`, `\` экранируются.
- `filter` — повторяемый, формат `column:op:value` (значение URL-кодировано); `is_null` без значения.
- `sort` — имя столбца, `dir` — `asc|desc`.
- `pageSize` — 1…200 (по умолчанию 50). Запись конкретной строки (FR-015) получается фильтром по первичному ключу.

## Ошибки
Тело: `{"error": {"code": "...", "message": "..."}}`, сообщения — фиксированные константы без причин.

| HTTP | code | Когда |
|------|------|-------|
| 400 | `invalid_filter`, `invalid_sort`, `invalid_page` | неизвестный/недопустимый столбец, оператор, значение |
| 404 | `unknown_table` | база или таблица не найдена в каталоге |
| 404 | `not_found` | неизвестный путь под `/api/` |
| 405 | `method_not_allowed` | не `GET` |
| 503 | `database_unavailable` | БД недоступна (затрагивает только запрошенную базу) |
| 500 | `internal` | запрос к базе отвергнут или завершился сбоем (причина не раскрывается) |
| 504 | `query_timeout` | превышено 5 с — «сузьте условия» |

## Гарантии
- Значения sensitive-столбцов не передаются ни в каком виде.
- Значения `q` и фильтров не попадают в логи.
- Ответы не кэшируются (`Cache-Control: no-store`).
