# HTTP Contract: cabby-gateway

## Публичная команда

| Свойство | Значение |
|---|---|
| Метод и путь | `GET /healthz` |
| Публичный порт | `CABBY_GATEWAY_PORT` из `backend/cabby-gateway/.env`; пример — `127.0.0.1:8082`, без переменной — 8080 |
| Аутентификация | Не требуется |
| Тело запроса | Не используется; дополнительные данные не меняют результат |
| Изменение состояния | Бизнес-состояние не меняется; технический счётчик вызовов увеличивается |

### Результаты

| Условие | HTTP | Тело | Учитываемый исход |
|---|---:|---|---|
| Сервис способен обрабатывать команду | 200 | `{"status":"ok"}` | `success` |
| Сервис принял команду после перехода в состояние неготовности при корректной остановке или при внутреннем отказе обработки | 503 | `{"status":"unavailable"}` | `failure` |
| Сервис не отвечает | ошибка соединения или таймаут клиента | нет ответа | не учитывается сервисом |

Ответы 200 и 503 используют `Content-Type: application/json`. Тело не содержит внутренних сведений, секретов или пользовательских данных. Клиент считает успешным только HTTP 200 с `status=ok`; все другие исходы означают, что положительная проверка не подтверждена.

Неготовность при остановке устанавливается до прекращения приёма запросов. Если запрос успел попасть к обработчику в этот промежуток, он получает 503; после закрытия слушателя клиент получает ошибку соединения или таймаут. Для воспроизводимой проверки ветки 503 тесты подменяют внутреннее состояние готовности, не открывая дополнительной публичной команды. В обычном запуске серия неуспешных вызовов может оставаться нулевой.

### Неподдерживаемые операции

- Любой другой путь возвращает 404.
- Метод, отличный от GET, на `/healthz` возвращает 405; это относится и к HEAD. Для корректного запрета HEAD обработчик проверяет метод явно, поскольку сопоставление `GET` в Go также принимает HEAD.
- Запросы к неподдерживаемым операциям не увеличивают счётчик health-check и не выполняют бизнес-действий.
- `GET /metrics` существует только на отдельном внутреннем порту и является техническим интерфейсом для Prometheus, а не публичной командой.

## Совместимость

Контракт вводится впервые; выпущенных клиентов нет. Формат `status` и значения фиксированы для первого выпуска. Будущие изменения контракта должны сохранять существующую проверку или сопровождаться планом миграции.
